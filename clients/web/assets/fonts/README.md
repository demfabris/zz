# Browser client fonts

The browser client ships Inter from [rsms/inter](https://github.com/rsms/inter)
under the SIL Open Font License 1.1.

| File | Face |
| --- | --- |
| `inter/InterVariable.ttf` | Inter Variable upright |
| `inter/InterVariable-Italic.ttf` | Inter Variable italic |

The full license is in [`inter/LICENSE.txt`](inter/LICENSE.txt), beside the fonts.
The browser client ships no CJK or emoji fallback; unsupported glyphs render as
missing glyphs.
